# Summarizing

Read when the request permits selecting and omitting information: summaries, TL;DRs, recaps, or extracting main points. Cleanup alone does not permit omission.

## Select What Matters

Identify the requested audience, purpose, scope, and length. If unspecified, retain the conclusion and information needed to understand or act on it. A summary of the whole text differs from extracting only deployment instructions.

Preserve decision-critical conditions, exceptions, negations, uncertainty, dates, numbers, units, dependencies, risks, and required step order. Keep disagreements and unknowns when they affect the conclusion. Supporting examples and repetition may be omitted within scope.

Do not replace a qualified conclusion with an unconditional claim. A proposed change is not completed work; merged work is not automatically released; a correlation is not automatically a cause.

## Check Against the Source

Compare the summary with the original. Can the reader make a different decision because a qualification disappeared? If so, restore it. Never add a source, measurement, cause, plan, or successful validation absent from the source.

If a strict length limit cannot contain every critical qualification, state the limitation briefly or ask which scope to prioritize. Do not hide the conflict by silently deleting a warning.

Match the requested output shape. Use a short paragraph for one main idea, a comparison table for parallel alternatives, or numbered steps when sequence matters. Return the summary first without a generic introduction or repeating conclusion.
