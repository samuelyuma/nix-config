# English

Read for English humanization, vocabulary cleanup, or wording examples. Routine English writing uses the core without loading this list.

## Familiar Words

| Usually Replace | With |
|---|---|
| utilize, leverage | use |
| facilitate | help, allow |
| comprehensive | complete |
| enhance | improve |
| streamline | simplify |
| subsequently, prior to | then, before |
| commence, terminate | start, stop |
| demonstrate | show |
| numerous, myriad | many |
| approximately | about |
| methodology | method |
| in order to, due to the fact that | to, because |

Choose by meaning, not string replacement. Preserve technical uses such as "robust statistics", proper names, quotations, and terms being discussed. Claims such as "seamless" or "game-changing" need evidence or a concrete description rather than a less fancy adjective.

## Sentence Habits

Use verbs rather than noun chains: "Validate the inputs", not "perform the implementation of input validation". Split stacked clauses when the reader must backtrack. Name the actor when it matters, but keep natural passive sentences when the actor is unknown or irrelevant.

Keep one accurate qualifier when uncertainty is real. "May fail" and "fails" are different claims. Repeat the same term instead of cycling through synonyms for variety.

Before: "This comprehensive guide will help you leverage our robust API in order to seamlessly integrate authentication."

After: "This guide shows how to add authentication with the API."
