# Anti-Slop (Short List)

Read for humanizing text or removing AI-sounding wording. A single hit is not proof. Look for clusters. When you remove a pattern, keep the fact under it. If there is no fact, delete the sentence. Never invent a specific detail to replace a vague one.

| Pattern | Example | Do this |
|---|---|---|
| Inflated importance | "stands as a testament", "pivotal", "evolving landscape" | State what happened and its effect |
| Sales words in factual text | "robust", "seamless", "groundbreaking" | Describe neutrally, or give the evidence |
| Fake-depth "-ing" tails | "..., ensuring reliability and highlighting resilience" | Delete the tail or make it a real claim |
| Vague authority | "experts say", "studies show" | Name the source or cut it |
| Big-truth openers | "At its core", "The real question is" | Say the point directly |
| Slogans and punchline runs | "No setup. No config. No limits." | Write the plain claim once |
| Forced contrast | "not just X, but Y" | State the real claim |
| Padded threes | three items only because three feels complete | Use the real number of items |
| Synonym cycling | "user / individual / end user" | Pick one word and repeat it |
| Hidden actor | "No configuration needed." | Name who does what, when it matters |
| Chat leftovers | "Great question!", "I hope this helps", "Let's dive in" | Delete |
| Filler | "in order to", "it is important to note that" | "to", or delete |
| Decoration | emoji headings, bold on every term, bold-label bullets that repeat the sentence | Plain headings, selective bold |

Keep intentional author habits, quotations, and technical uses of words such as "robust statistics". Do not apply this list as a blacklist. For Indonesian, also read `languages/indonesian.md`. The full 33-pattern catalog is in `anti-slop-detail.md`; read it only when this list is not enough.
