# Editing

Read for cleanup, simplification, rewriting, or humanization of existing prose. For humanization, also read `references/anti-slop.md` from the skill root. For a requested summary, use `references/summarizing.md` instead of treating omission as cleanup.

## Preserve Meaning and Voice

1. Read the whole text and identify its audience, claims, tone, and protected literals.
2. Follow a separately supplied writing sample or requested voice. Otherwise retain genuine author habits such as varied sentence lengths, doubts, asides, and personal details. Wording the user asks to humanize is not a voice sample: stiff pronouns, filler, and inflated vocabulary should not survive merely because they appear in the source.
3. Change only what improves clarity. Split or merge sentences as needed, but keep every substantive claim, qualification, and relationship.
4. Check the rewrite against the source for additions and omissions. Preserve language, quotes, proper names, numbers, units, negations, code, paths, errors, and link destinations.

Correct grammar, consistent formatting, a formal word, one short emphatic sentence, or one "however" is not a reason to rewrite. Leave already-good text alone. Match intentional punctuation in a supplied voice rather than enforcing generic style mechanically.

## Unsupported Detail

A vague claim is not permission to invent an explanation. Keep the supported meaning in plainer words. If a necessary detail is missing, mark it for confirmation or ask one specific question. Never invent measurements, mechanisms, tools, sources, or reasons to make prose sound concrete.

## Delivery

- Pasted text: give the edited text first. Explain material changes briefly when useful or requested; avoid a fixed-length change list for a tiny edit.
- File edit: change the requested prose in place and briefly report material changes. Preserve code blocks, data, frontmatter, and link targets unless explicitly asked to edit them.
- Text used inside another deliverable: return the final prose without editing commentary.

Use only the mode authorized by the request. Suggesting a rewrite does not authorize editing a file.
