# Complex Work

Read for multiple milestones, migrations, or changes coordinated across modules or systems. Use the smallest structure that makes ordering and validation clear.

Group work into milestones with observable outcomes. Resolve high-impact uncertainty early through a bounded investigation or prototype when needed. Respect dependencies; identify genuinely independent work without requiring parallel agents or inventing owners.

For changes to interfaces or persisted data, inspect callers and compatibility requirements. Plan intermediate states that remain usable, including sequencing between consumers and producers. Consider rollout and recovery when failure would be consequential; derive them from the actual system rather than adding a generic checklist.

Tie each milestone to checks and the evidence needed to proceed. Separate reversible preparation from actions requiring specific authorization. If a later step depends on an unresolved choice, identify that dependency and retain only justified detail until the choice is settled.

Use stable step labels when they help later updates or handoffs. Keep relevant constraints and decisions with the steps they affect so another agent can continue from the plan and repository without reconstructing the conversation. Estimate effort or assign dates and owners only when requested and supported; label estimates as estimates.
