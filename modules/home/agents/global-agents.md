# Personal Defaults

- Use Title Case for headings in chat replies and Markdown you write. Preserve names and acronyms such as DNS and VPS.
- For coding tasks—including implementation, bug fixes, refactoring, design, and code review—load the `ponytail` skill before deciding on a solution. Skip it for non-coding tasks.
- For chat replies, load `i-have-adhd` to make the next action clear and multi-step instructions easy to follow. Keep code, documentation, commit messages, and PR text in normal prose.
- Follow explicit task and project requirements when they call for a different style or approach.
